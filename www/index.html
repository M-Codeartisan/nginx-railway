NGINX on Railway Static hosting, reverse proxy and edge caching — configured entirely by environment variables.

This page is the shipped placeholder. It was copied onto the volume at /data/www the first time this service booted, and it is only seeded while that directory is empty — upload your own files and they are served instead.

Serve your own site

Upload files to the volume at /data/www, or point SITE_SOURCE_URL at a .tar.gz and it is unpacked on boot. Set SPA_MODE=true for a single-page app so unknown paths fall back to index.html.

Reverse proxy

Route paths to other Railway services with PROXY_ROUTES. An upstream ending in / strips the matched prefix. Upstreams are re-resolved as they change, so redeploying a backend never strands a stale address.

Real client IP

Railway's edge appends a rotating address to X-Forwarded-For. This config reads the leftmost entry, so logs, rate limits and forwarded headers all carry the true client.

Compression

gzip is on for text, JSON, SVG and fonts, and gzip_static serves a pre-compressed .gz sibling whenever one is uploaded beside the original.

Edge cache

Set CACHE_ENABLED=true to cache proxied responses on the volume. Every response then carries an X-Cache-Status header.

Locked down by default

Server tokens off, dotfiles denied, HSTS and the usual security headers on every response, and optional HTTP basic auth over the whole site.

Put NGINX in front of your other services

# One public domain, several private Railway services behind it.
PROXY_ROUTES=/api=http://api.railway.internal:3000,/auth=http://auth.railway.internal:9000

# Everything not matched by a route is served from the static site root.
SPA_MODE=true
CACHE_ENABLED=true

Settings

VariableDefaultWhat it does
SITE_ROOT/data/wwwDirectory served as the site root.
SITE_SOURCE_URLunsetArchive unpacked over the site root at boot, once per URL.
SPA_MODEfalseFall back to index.html for unknown paths.
PROXY_ROUTESunsetComma-separated /path=upstream reverse-proxy routes. A trailing / on the upstream strips the prefix.
CACHE_ENABLEDfalseCache proxied responses on the volume.
BASIC_AUTH_USERunsetEnables HTTP basic auth when set with a password.
RATE_LIMIT_RPSunsetRequests per second per client IP.
DIRECTORY_LISTINGfalseServe an index of directories with no index file.
