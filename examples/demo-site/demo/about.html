About these notes

Three files, one directory, no build step.

This second page exists to prove an ordinary thing: links between pages work, the shared stylesheet is fetched once and cached, and the server resolves about.html without any routing configuration. A static site does not need more than that.

Deep links

Requests that match no file return a real 404 by default. For a single-page app, turning on SPA_MODE makes unknown paths fall back to index.html so the client-side router can handle them instead.

Where to go next

  • Turn on caching so proxied responses are served from the volume.
  • Add basic auth while the site is still a draft.
